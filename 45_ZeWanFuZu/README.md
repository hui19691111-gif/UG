# 折弯辅助板（ZeWanFuZu）

NX 2412 原生独立命令，保留智辉插件的授权入口。选择当前工作零件的板厚面，可多选。

选入板厚面后自动切换到“折弯参考边（可选）”。若需追加其他面，可点回“选择板厚面”继续选择；仅切回选择框或移除已选面时不会自动跳走。“应用”成功后清空选择并返回板厚面，便于继续创建。只有一个折弯方向时仍可不选参考边，直接应用。

## 创建规则

1. 支持直线边界的平面板厚面，以及平板外轮廓圆弧对应的圆柱板厚面。从两侧平行大面识别板厚；圆弧板厚面的圆柱轴线须垂直于大面，两侧圆弧同半径。
2. 沿相邻折边的大面找到圆柱折弯面，取与大面相切的直线折弯边。排除圆孔壁和单侧自由边圆角。
3. 直线板厚面用折弯边方向与板厚面法向的点积判断平行关系，角度容差为 `1e-6`。平行的面直接跳过；非平行的面创建辅助板，定位边平行于折弯边。圆弧不是整段平行，不因最高点处的切线平行而跳过。
4. 同一折边含多个不同方向的折弯时，要求选择该折边上的折弯参考边，避免误判方向。
5. 生成与原板等厚的辅助板，通过两处微连接求和为同一实体；一次“应用”对应一个可撤销操作。预览只画临时轮廓，不修改零件。
6. 圆弧输入的辅助板内边使用真实同心圆弧，不以折线建模，也不平移圆心。凸弧偏置半径为原半径加间隙，凹弧为原半径减间隙，使可见间隙沿法向等距；直线输入使用平行线法向偏置。微连接根部略微进入原板以完成求和。自动对齐使用完整轮廓的精确圆弧极值，定位边仍为平行于折弯边的直线。

## 参数（统一为毫米）

| 参数 | 默认值 | 定义 |
|---|---:|---|
| 辅助板宽度 | 10 | 沿折弯边方向投影测量 |
| 微连接宽度 | 1 | 每处连接沿折弯边方向的宽度 |
| 微连接缩进 | 3 | 两处连接分别从辅助板左右端向内缩进 |
| 中间间隙 | 2 | 原板边与辅助板内边之间的法向距离；圆弧为同心圆弧半径差，直线为平行线垂直距离 |
| 距离端点 | 5 | 从所选边较低端开始，沿折弯边方向投影测量；圆弧也使用投影距离，不是弧长 |
| 辅助板高度 | 50 | 手动模式下，从辅助板起点处的原板边界到定位边的高度 |
| 自动对齐 | 开 | 定位边对齐所在折边大面的最高处；同体、同平面、同方向的多个输入共同对齐；此时高度输入禁用 |
| 翻转端点 | 关 | 改从另一端定位 |

宽度必须大于两倍“缩进 + 微连接宽度”。微连接落在原板外、尺寸超出输入边界或自动定位边过低时，提示修改参数，不生成不完整实体。英寸零件自动换算。

凹弧间隙必须小于原弧半径；若偏置圆弧无法覆盖所选宽度，请增大距端点、减小宽度或减小间隙。旧版本生成的非均匀间隙不会自动更新，请撤销原辅助板后重新创建。

当前支持直线及圆弧外轮廓的等厚板厚面，所在折边须有可识别的圆柱折弯。圆弧支持凸弧、凹弧及半圆，但沿折弯方向的投影必须不回绕；超过半圆或发生回绕时需先分割。圆孔内壁、样条曲边、非等厚面、无可识别折弯和装配组件输入会提示处理。圆弧上的辅助板覆盖最高点且超出自动对齐高度时，可调整位置/宽度，或关闭自动对齐后增大高度。

## 自定义特征与编辑

每块辅助板生成一个“折弯辅助板”自定义特征，内部拥有拉伸、求和与轮廓曲线，使用专用图标。双击特征恢复该块辅助板自己的六个尺寸及两个开关，可修改后更新原特征；不会追加第二块辅助板。编辑原位替换拉伸截面，保留原拉伸和求和标识，支持缩进改为零时轮廓段数变化。

所选实体已存在展开图或展开实体特征时，创建前根据展开的输入面匹配所属实体，在该实体最早的展开特征之前插入辅助板及内部拉伸、求和；完成后恢复原当前特征并更新展开。不会按名称或其他实体的展开来确定插入位置。连续创建的辅助板仍位于展开之前。编辑时在辅助板对应的历史位置更新，再向后更新展开，避免对展开后的体进行辅助板几何校验。旧版已创建在展开之后的辅助板不会自动调整顺序，需要撤销后重新创建。

编辑以创建时保存的板厚面定位数据为基准，自动对齐高度也保留创建时的共同定位高度。编辑时不重新选择板厚面；如果源板轮廓、板厚或折弯方向改变，需要重新创建辅助板。源板改变后不会自动重算识别逻辑。旧版普通特征组没有保存这些定位及参数数据，不自动转换，撤销旧辅助板后重新生成即可。

新增自定义特征类需要保存零件并重启 NX 后注册。Core DLL 常驻以处理特征读取与内部成员；UI DLL 保留授权检查并在对话框关闭后卸载。

参考：[博士钣金官方折弯辅助教程](https://bsbanjin.com/8999.html)。按用户提供的六个参数及“平行跳过”规则实现，未复制第三方程序代码。

## 构建与验证

```powershell
cmake -S . -B build-codex -A x64 '-DNX_ROOT=D:/Program Files/Siemens/NX2412' -DZH_BEND_ASSIST_TESTS=ON
cmake --build build-codex --config Release
# NXBIN 在 PATH 中，使用新的测试输出目录。
build-codex/Release/BendAssistIntegration.exe <新建输出目录>
```

外部 NX 测试创建带真实圆柱折弯的斜边与圆弧边钣金，覆盖毫米、旋转、英寸、凸弧/凹弧及从半圆端点开始的较宽辅助板。检查生成实体的间隙圆柱面与原弧同心、半径差等于输入间隙，同时验证平行判断、误选拒绝、圆弧极值、定位高度、翻转端点、参数边界、微连接/间隙点位、实体增量体积及撤销。自定义特征测试还检查内部成员、尺寸修改、零缩进、内部特征标识不变、撤销编辑、保存后重新打开并再次编辑。测试时 `UGII_USER_DIR/application` 需包含本项目的自定义特征 XML 和 Core DLL。测试程序和测试零件不部署。

已有展开的回归用例覆盖斜边、圆弧边、多实体和独立展开实体，检查整个辅助板构造链的先后顺序、原当前特征恢复、展开实体的实际体积更新、重复创建、编辑回滚、撤销和保存后重新编辑。

运行 `python tools/deploy.py` 部署 DLL、Core DLL、DLX、图标、菜单和合并后的共享自定义特征 XML，并完成 NX 界面验证。备份原文件和两份清单，验证 PE 保护标记、校验和、授权入口、导出入口及哈希，保留共享 XML 中其他命令的注册项。新菜单和自定义特征类在重新启动 NX 后显示。
