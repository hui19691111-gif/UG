# 用户自己添加有参标准件

本版已经把参数定义做成可编辑表格，不需要手写配置文件。

1. 在 NX 中用表达式驱动模型尺寸，例如 D、L、K。公式关系直接建在 PRT 中，例如 K=D/2。先保存 PRT；部件存在未保存修改时，程序会提示先保存。
2. 打开智辉标准件库 → 本地有参 → 图档管理。
3. 选择“用当前部件新建有参”，或“选择 PRT 新建有参”。填写分类、零件族和首个规格名称；新建零件族不能与已有目录重名。
4. 在“定义参数”表格中选择需要显示的 NX 表达式，填写中文名称和输入方式。新定义默认空白，不会自动加入模型中的表达式；只保存用户选择的行，可配置 1–12 个数值参数。下拉框中可选择 PRT 的数值表达式；自动生成的 p… 表达式也可手动选择，建议先在 NX 中改成易懂的名称。
5. 选择“创建有参零件族”。程序复制 PRT 和同名图片，并建立参数定义、首个规格表和库索引。
6. 选择新零件族 → 图档管理 → 管理参数。修改可编辑尺寸，填写新规格名，按“另存规格”；模型公式自动更新，完成后回到新规格。

插入时无需先到图档管理另存：本地有参 → 选择零件族 → “选择参数”。这里显示已经定义的全部参数，下拉参数可选规格值，数值参数可直接输入，固定参数和公式联动值只读。按“选用此参数”，已有相同参数的规格会直接选中；新的参数组合会自动生成并加入规格列表，保留原模板。随后指定插入点和方位，按“应用”或“确定”。先选好的插入点、方位和放置选项会在生成新规格后恢复。

例如长、宽、高分别绑定 p7、p8、p1，定义为下拉选择后，可在插入窗口中选取 80、30、20。主界面仅摘要显示前四项；“选择参数”中可查看并操作全部已定义项。只希望用户调整几个尺寸时，在“定义参数”中仅保留这些行，其他行可清空。

同一零件族可以保存多套命名的参数组。在“选择参数”或“管理参数”中填写尺寸和组名称，点击“保存参数组”。例如方体 A组保存长100、宽50、高30，B组保存长80、宽40、高20；以后直接在主界面“选择参数”按钮右侧的下拉框选择 A组或 B组，下方尺寸和待插入模型一起切换，无需再打开参数窗口确认。新尺寸首次选用时自动生成规格，再恢复插入界面和定位设置。“选择参数”按钮继续用于编辑尺寸、添加和管理组。同名保存更新当前组，改名保存为新组；“删除选中组”只删除尺寸方案，已生成的规格和 PRT 保留。修改、删除前会备份到库的 backup 目录。当前尺寸不属于任何组时显示“当前尺寸（自定义）”；没有参数组的零件仍显示原规格列表。

参数组只保存已定义的可编辑尺寸，每个零件族独立保存，所有规格共用。固定和公式尺寸仍由当前 PRT 决定，生成模型时公式自动更新。中文名称和显示顺序变化不会导致组内尺寸错配；增加参数或收窄可选范围后，如果旧组缺少尺寸或数值不再允许，先选择“当前规格尺寸”修正数值，再保存为原组名。每个零件族最多 200 组；未定义参数组的旧标准件可继续直接输入尺寸。

| 输入方式 | 用途 | 示例 |
| --- | --- | --- |
| 数值输入 | 用户输入任意有效数值，模型负责约束其有效范围 | 长度 L |
| 下拉选择 | 从指定数值中选择；填写可选值并用分号隔开，必须包含当前值 | 10;20;30;40 |
| 固定显示 | 显示尺寸，调用时不允许修改 | 公称直径 D |
| 公式联动 | 显示由 PRT 计算的值，保存规格时更新 | K=D/2 |

公式、测量和锁定表达式不能改成“数值输入/下拉选择”，防止覆盖公式。输入单位沿用 NX 表达式本身的单位。当前只管理数值表达式，不支持把字符串、点或向量表达式作为尺寸输入。

已有有参 PRT 如果尚未配置参数，点击“管理参数”会直接进入定义表格；也可以用“定义参数”修改已有配置。修改定义会读取该零件族所有规格的真实数值并保留每份 PRT，更新前备份旧参数文件到库的 backup 目录。

图片可预先与 PRT 同名放在一起，或在入库后通过“抓取选中图档图片”保存当前视图。抓图前应显示所需模型和视角；抓图会去除选择高亮和方位手柄。

在零件列表中右键点击标准件，可以选择“更换预览图片”（PNG/JPG/BMP）或“抓图作为预览”。修改作用于当前选中的规格，旧 PNG 先备份，新图立即显示。有参件的右键菜单还提供“参数组 / 选择尺寸”和“修改参数设定”，可直接调整参数组、中文名称、表达式绑定和输入方式。

插入时，X轴模式使用 X数、X距，Y轴模式使用 Y数、Y距；数量包含全部放置件，以插入点为中心排列，方向跟随所选插入方位。二维“阵列”数量为 X数×Y数。单点、对角、4角、居中分别保持 1、2、4、1 个放置位置。

有参模型保留其 PRT 原点和坐标轴作为插入基准。建议建模时将预期插入点放在原点，并确定轴方向；不要用无参“选择体加入库”代替有参模板入库。

新建图档使用“零件族_规格.prt”作为实际文件名，界面仍显示填写的规格名称，减少 NX 装配中同名部件冲突。若 NX 已加载了另一目录下的同名文件，程序会提示冲突，不会读取或关闭那个部件。

本功能参考燕秀“中文标签、输入控件、表达式、规格值分层”的管理方式，使用自己的 PRT 与参数文件格式。本版没有直接导入燕秀 XLSX、执行燕秀表达式脚本或显示其 DimControls 图形尺寸手柄；不能将本功能描述为燕秀格式完全兼容。
