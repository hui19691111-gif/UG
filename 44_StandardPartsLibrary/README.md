# 智辉标准件库

本地标准件库实现：

- 用户可从当前已保存的 NX 部件或外部 `.prt` 文件入库。
- 采用燕秀类标准件库工作流：无参/有参库切换、分类、零件族、规格、右侧预览与底部定位。
- 本地无参库位于 `Lib`，本地有参/多规格库位于 `LibParam`；程序会递归扫描目录中的 `.prt`。
- 标准件可以附带同名 `.png`、`.jpg`、`.jpeg` 或 `.bmp` 预览图，右侧优先显示配图，没有配图时读取 PRT 自带缩略图。
- 同一分类、同一零件族下可以保存多个规格，调用前从“规格”下拉框选择。
- 支持 WCS 原点、任意点、面中心、圆/圆弧中心以及 NX 动态坐标系快速定位。
- 支持指定放置图层和选择目标实体自动修剪；装配模式会保留组件并隐藏内部修剪工具体。
- 独立“修改配置”窗口可以更换库根目录并打开无参/有参目录进行维护。
- 装配调用：在当前 WCS 位置和方向创建组件实例。
- 多实体调用：在当前 WCS 位置和方向将模型合并到当前工作部件。
- 默认库目录为 `D:\UG智辉标准件库`，与插件安装目录分离，升级不覆盖用户数据。
- 对话框关闭后立即卸载 DLL，不保留进程级 UI 状态。

默认目录结构：

```text
D:\UG智辉标准件库
├─ Lib\分类\零件族\规格.prt
├─ Lib\分类\零件族\规格.png
├─ LibParam\分类\零件族\规格.prt
├─ LibParam\分类\零件族\规格.png
├─ library.tsv
└─ backup
```

索引使用 UTF-16 TSV 文件 `library.tsv`。目录中的 PRT 即使没有写入索引，也能由刷新操作自动发现；索引修改采用临时文件替换，旧索引自动备份到 `backup`。
