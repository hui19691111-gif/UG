# 智辉标准件库

本地标准件库实现：

- 用户可从当前已保存的 NX 部件或外部 `.prt` 文件入库。
- 采用燕秀类标准件库工作流：无参/有参库切换、分类、零件族、规格、右侧预览与底部定位。
- 本地无参库位于 `Lib`，本地有参/多规格库位于 `LibParam`；程序会递归扫描目录中的 `.prt`。
- 标准件可以附带同名 `.png`、`.jpg`、`.jpeg` 或 `.bmp` 预览图；右侧只读取这些安全的配图，避免 NX 的 PRT 缩略图提供程序重入界面线程造成卡死。
- 标准件列表支持右键“删除当前规格”（或 Shift+F10）：右键另一行先选中该行，同一行保留当前规格，空白处不提供删除。确认默认“否”；删除只针对当前规格，未共用的库内 PRT 和同名配图移到库内 `backup/deleted_*`，附带 `restore.tsv` 恢复记录。其他规格共用的模型保留；索引保存失败会恢复已移走的文件。
- 同一右键菜单支持“编辑标准件 PRT”：结束标准件库对话框并清除临时预览后，将当前规格的库内源 PRT 设为工作/显示部件，不关闭或自动保存原工作模型。已加载的源部件直接复用；编辑后手动保存会影响后续标准件调用。
- 主界面左下“选择体加入库”直接切换到 NX 原生入库对话框，无需先手动取消主界面。对话框提供标准件名称、分类、规格、多实体选择、基准点 XYZ、模型拾取点和“指定方位”；选点后可调整三轴方位，点坐标与方位控件原点联动。“应用”入库后可继续下一次选择，“确定”完成入库并返回库列表，“取消”返回库列表。只允许当前工作部件的实体（不支持装配发生体），保存到本地无参库；将基准点归一到 PRT 原点、所选方位归一到 PRT 坐标轴，未调整方位时默认绝对坐标轴。后续装配或多实体插入按此基准对齐。原实体位置和原 WCS 保持不变，不自动保存来源工作件；同名规格另存编号文件。
- 同一分类、同一零件族下可以保存多个规格，调用前从“规格”下拉框选择。
- 入库对话框支持“抓取图片（当前模型视图）”：先调整模型视角及显示内容，再抓取白底 PNG；图片包含当前视图区中可见的模型及标注。抓取时清除实体、拾取点关联对象及全局选择的高亮，抓取后不强制恢复高亮，保留入库实体选择和基准点；方位手柄及其悬浮输入框在抓图期间隐藏，完成后可继续调整方位。“应用/确定”将图片与 PRT 按相同文件名保存，库列表自动显示预览；再次抓取替换待保存图片，“清除图片”取消本次配图，取消对话框清理临时图片。每次成功入库后图片状态清空，下一件需重新抓取；已有模型或同名配图不会被覆盖，入库失败会回滚本次文件。
- 支持任意点、面中心、圆/圆弧中心、点投影面，以及与 NX 原生方位控件联动的快速定位。
- 快速定位支持保留当前方位、WCS、ABS、X/Y/Z 角度、单轴翻转、三轴同时旋转和轴锁定；取消会完整恢复进入快速定位前的原点与方向。
- 支持单个、X 轴、Y 轴、对角、四角、居中和矩形阵列放置，阵列可输入 X/Y 间距与数量；居中模式以所选目标实体的包围盒中心为准。
- 支持指定放置图层和选择目标实体自动修剪；装配模式会保留组件并隐藏内部修剪工具体。
- 批量放置作为一次 NX 撤销事务执行；任一位置失败会回滚本次已创建对象，不留下半成品。
- 本地有参和本地无参分别维护分类、搜索、零件族、规格及图档管理。切换库会关闭上一库的管理窗口；“全部”只清除当前库的筛选。目录分别为 `LibParam` 和 `Lib`，按实际目录纠正旧索引中的类型标记。
- “图档管理”只显示当前库的入库入口和目录。有参库提供“管理参数”：中文尺寸名、NX 表达式、固定/列表/数值/公式尺寸分列显示；另存新规格时更新模型表达式及规格表，保留原图档。NX 保存完成后自动返回有参库并选中新规格，避免在原生对话框内保存造成取消时撤销标记失效。
- 图档管理支持“抓取选中图档图片”：将当前模型视图保存为选中 PRT 的同名白底 PNG，去除选择高亮和方位手柄，替换旧图前备份。另存的有参规格尚无同名图片时可使用系列目录下的 `parameter-preview.png` 示意图。
- 选中标准件及规格后，指定有效插入点会启用“确定/应用”；选点时保留输入，不自动创建模型。按应用后可继续指定下一位置；成功放置的位置只消费一次，再按确定不会重复插入。取消保留此前已经成功应用的实例。
- “确定/应用”使用显式启用回调，不受隐藏辅助选择和可选修剪目标的必选状态阻塞；若尚未选择标准件，或启用自动修剪但未指定目标，点击时会提示具体原因。
- 有效选点后显示标准件实体边缘的临时线框预览，跟随规格、插入点、方位与阵列变化；正式插入或取消时清除，不创建预览实体或特征节点。预览不模拟自动修剪；复杂模型自动切换为各实体的简化外形框，超大阵列进一步合并为整体外形框，状态栏明确提示，绘制始终不超过 5000 段。简化框仅用于定位，不代表精确轮廓；正式插入仍使用完整模型。无实体轮廓的模型仍提示无法预览。
- 装配调用：在指定位置和方位创建组件实例，引用整个部件，不要求自定义 PRT 存在 `MODEL` 引用集。
- 多实体调用：在指定位置和方位将模型合并到当前工作部件。
- 默认库目录为 `D:\UG智辉标准件库`，与插件安装目录分离，升级不覆盖用户数据。
- 对话框关闭后立即卸载 DLL，不保留进程级 UI 状态。
- Release 入口保留授权和防篡改校验；授权失败会显示具体原因，不再表现为按钮无响应。
- 部署时须将 `StandardPartsCapture.dlx` 与 `StandardPartsLibrary.dlx`、`StandardPartsLibrary.bmp` 一同放到 DLL 所在目录。

默认目录结构：

```text
D:\UG智辉标准件库
├─ Lib\分类\零件族\规格.prt
├─ Lib\分类\零件族\规格.png
├─ LibParam\分类\零件族\规格.prt
├─ LibParam\分类\零件族\规格.png
├─ library.tsv
└─ backup
```

索引使用 UTF-16 TSV 文件 `library.tsv`。目录中的 PRT 即使没有写入索引，也能由刷新操作自动发现；索引修改采用临时文件替换，旧索引自动备份到 `backup`。

## 国标有参库

用户可在“本地有参 → 图档管理 → 选择 PRT 新建有参”（或“用当前部件新建有参”）直接建库。程序读取已保存模型的数值表达式，支持中文名称、数值输入、下拉选择、固定显示和公式联动；创建后用“管理参数”另存规格，用“定义参数”调整同系列参数表。操作说明见 [用户自建有参库说明](用户自建有参库说明.md)。这是对燕秀参数管理流程的参考，不直接兼容其 Excel、脚本及 DimControls 文件。

`library-flat` 新增 GB/T 70.3-2023 内六角沉头（平头）螺钉，M3/M4/M5/M6/M8/M10/M12 共 75 个规格。长度包含头部，插入基准为头顶中心。PRT 使用 `GB70_3_` 文件名前缀，可与同规格圆柱头螺钉同时加载。用户新建/另存图档使用“零件族_规格”文件名，防止 NX 误用其他目录的同名图档。详见 `library-flat/GB_T70.3平头有参库说明.md`。

`library` 包含独立制作的 GB/T 70.1-2008 内六角圆柱头螺钉，M3/M4/M5/M6/M8/M10/M12 共 87 个规格，原生 NX2412 特征、命名表达式、粗牙右旋符号螺纹、无高亮预览及中文参数表。详见 `library/GB_T70.1有参库说明.md`。

`tests/GenerateGbSocketLibrary.cpp` 在新的隔离目录中生成 PRT；`RenderScrewPreviews.py` 由生成的 STL 渲染配图；`PackageScrewLibrary.py` 检查网格闭合和正体积并输出文件清单。安装时追加合并索引，不能覆盖用户索引。

`StandardPartsParameterTest.exe <新的测试目录> <M6 系列目录>` 使用真实 NX 验证分类隔离、旧类型纠正、参数另存、L/B 实体联动、源件不变及失败回滚。预校验不创建文件、不清除撤销标记；实际 NX 保存放到主对话框关闭之后执行。测试及生成工具不得部署到插件运行目录。

## 放置回归验证

配置 `-DZH_STANDARD_PARTS_TESTS=ON` 可构建 `StandardPartsPlacementTest.exe`。在可用的 NX 外部运行环境下，传入一个尚不存在的临时目录；测试创建独立模型，直接调用生产代码的装配/多实体函数，验证两次放置的数量和坐标，以及整个部件引用集。测试程序仅用于开发，禁止部署到插件目录。

`tests/CreatePlacementFixture.cs` 可通过 NX `run_journal.exe` 生成独立的毫米单位平板与三个点，供交互选点测试使用。测试不能代替实际对话框回归：发布前还必须打开对话框、每个动态模式切换两遍、反复选择/替换输入、应用后继续操作，再取消/关闭。
