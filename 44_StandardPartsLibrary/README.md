# 智辉标准件库

本地标准件库第一阶段实现：

- 用户可从当前已保存的 NX 部件或外部 `.prt` 文件入库。
- 按分类和关键字搜索标准件。
- 装配调用：在当前 WCS 位置和方向创建组件实例。
- 多实体调用：在当前 WCS 位置和方向将模型合并到当前工作部件。
- 默认库目录为 `D:\UG智辉标准件库`，与插件安装目录分离，升级不覆盖用户数据。
- 对话框关闭后立即卸载 DLL，不保留进程级 UI 状态。

索引使用 UTF-16 TSV 文件 `library.tsv`，模型存放在 `models` 子目录。索引修改采用临时文件替换，旧索引自动备份到 `backup` 目录。
