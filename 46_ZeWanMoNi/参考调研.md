## 从官方视频画面直接确认的功能

| 观察项 | 可见证据 | 对 UG 版本的要求 |
| --- | --- | --- |
| 刀具对位预览 | L 形零件的折弯位置出现刀具形体，折弯区域及刀具出现彩色高亮 | 根据选定折弯位置和方向放置刀具，显示零件与刀具的几何关系 |
| 单刀模式 | 面板存在“单刀模拟”按钮 | 第一版先完成一个折弯位置与一把刀具的检查 |
| 方向调整 | 面板存在“反转”按钮 | 提供刀具放置方向切换，并重新检查干涉 |
| 刀耳宽度 | 面板存在“刀耳宽”，所见输入值为 5 | 参数应进入模型和检查；尺寸具体定义仍需用后续教程/样件确认，暂不能把 5 写成产品固定默认值 |
| 无内圆角输入 | 面板提示无内 R 时选择边并输入内 R，所见输入值为 0.2 | 同时规划圆柱折弯面输入和锐边配合手动内 R 输入；两类输入需要分别验证 |
| 视图控制 | 面板存在“加入刀具后自动正视”选项 | 可选地将视图对正当前刀具/折弯截面 |
| 刀具列表 | 列表包含选择框、刀具名称和缩略图，多条刀具条目可见 | 提供本地刀具库及图形预览，快速替换刀具 |
| 自定义刀具 | 面板说明支持自定义刀具，并显示制作刀具的文字指引 | 定义本插件自己的刀具几何、坐标基准和缩略图约定，保留用户自行建库能力 |

不能仅根据红色或黄色画面判断“自动干涉报警”的具体规则。可能包含选择高亮；需要对照发生干涉/未干涉的完整操作及提示进一步核实。刀具干涉这一功能方向另外得到[官方更新日志](https://bsbanjin.com/369.html)的文字支持。

## 对首版范围的修正

先前 README 将上下模、工序排序、逐道成形与连续播放同时列为第一版目标，范围比本次已看到的参考功能更大。现在优先对齐：

**选择折弯位置 → 选择刀具 → 定位/反转 → 调整刀耳宽及内 R → 检查刀具与零件干涉。**

首版以“单处折弯的刀具干涉检查”为明确目标，采用 NX 原生对话框和几何预览。完整展开/成形动画、自动工序排序、上下模联动、后挡料和整机检查保留为扩展；本次没有足够视频证据确认参考工具具备这些功能。

## 下一步技术验证

1. 从圆柱折弯面及相邻平面建立折弯坐标系；对锐边输入明确内 R、板厚和参考侧。
2. 制作本插件独立的简单测试刀具，定义刀尖原点、刀具长度方向、截面朝向及反转方式，不依赖第三方刀具库文件。
3. 在模拟副本中放置刀具，检查干涉、接触及间隙；不得修改源钣金几何或把计算失败当作通过。
4. 用同一零件的“明显穿透、刚好接触、明确间隙”三组位置验证检测逻辑，再接入刀具列表、反转和自动正视。
5. 在“刀耳宽”的尺寸语义得到确认前，将该参数定义保持为待验证项，不能凭名称决定沿哪一方向改变刀具尺寸。
