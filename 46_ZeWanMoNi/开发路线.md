## 优先实现的第一版

先完成单个折弯位置的刀具干涉检查：选择圆柱折弯面（并验证锐边加手动内 R 的输入方式），从刀具库选刀，建立对位预览，切换方向，检查干涉并清晰显示结果。提供自定义刀具约定和可选自动正视。刀耳宽的具体尺寸定义待核实。

“显示刀具与零件的干涉”和“完成折弯过程中的连续碰撞检查”是不同的验收项。首版只声明实际实现并验证的检查范围。

## 后续完整工艺模拟路线

先支持当前工作零件中的单个等厚钣金实体、直线折弯和圆柱折弯区域。优先验证有钣金特征历史的原生 NX 零件。导入实体须完成钣金转换和可展开性检查后再进入模拟。

| 功能 | 交互和输出 | 验收重点 |
| --- | --- | --- |
| 选择与识别 | 选择实体和固定面，生成折弯列表，点击列表高亮对应区域 | 内外折弯面合并为同一道折弯；圆孔壁、外缘圆角不能误识别 |
| 工序编排 | 上移、下移、反向放料，显示编号、目标角度、半径和长度 | 调序后重新生成受影响的工序状态；不可执行时指出具体工序 |
| 刀模设置 | 选择上模、下模和长度，设置刀尖及 V 槽定位基准 | 长度、单位、方向和定位正确；首版优先使用用户确认的实际刀模 |
| 逐道模拟 | 展开态、上一步、下一步、成形态，显示当前工序 | 每道终态是有效 NX 几何；切换工序时折弯、孔和相邻板面一起更新 |
| 干涉检查 | 显示碰撞对象，区分穿透、接触、间隙不足、未检查和计算失败 | 接触不能直接当作碰撞，也不能把失败当作通过；明确已检查的对象和运动阶段 |
| 保存工艺 | 保存顺序、放料方向、刀模和设置，导出工序表 | 重开后可恢复；源零件变化后旧结果标记为失效 |
| 退出恢复 | 清理模拟副本，恢复选择和显示状态 | 取消、异常、重复进入时不残留临时实体，不改变源零件几何 |

连续播放在逐道终态正确之后实现。界面须明确区分“动画预览”和“已计算的干涉结果”。单纯改变视角或旋转整件不算完成折弯模拟。

## 使用流程与界面

```text
选择钣金实体 → 选择固定面 → 识别折弯 → 调整工序 → 配置刀模
                                                    ↓
保存工艺/工序表 ← 检查结果 ← 逐道模拟 ← 定位当前工序
```

采用 NX 原生对话框和图形窗口：

- 顶部：实体、固定面、重新识别。
- 中部工序列表：工序号、折弯编号、角度、方向、上模、下模、检查状态；提供上移和下移。
- 刀模区域：库条目、工作长度、安装方向、定位基准。
- 播放区域：展开态、上一步、下一步、成形态；后续加入播放、暂停及进度。
- 底部：当前工序详情、干涉对象及原因、保存工艺、关闭。

没有配置刀模时可查看零件工序形状，但刀模检查状态必须显示“未检查”。切换刀模、顺序、方向或源几何后，相关检查结果失效。

## 实现结构

采用 C++17 + NXOpen/UFUN，保留现有插件授权入口。以下模块名称为建议，尚未创建源代码。

| 模块 | 职责 |
| --- | --- |
| `BendRecognition` | 检查等厚性；提取板面、折弯区域和邻接关系；区分内外面与圆孔 |
| `BendTopology` | 建立板面与折弯连接关系，定义固定侧、移动侧，处理拆分面和相邻折弯依赖 |
| `ProcessPlan` | 保存工序、方向、刀模引用和参数，检测无效顺序，管理结果失效 |
| `NxSimulationSession` | 创建隔离的模拟副本，建立工序几何，管理撤销、异常清理和状态恢复 |
| `ToolLibrary` | 管理实际刀模几何及刀尖/V 槽基准、轴向、单位、工作长度和安装方向 |
| `InterferenceChecker` | 候选筛选、实体精确检查、间隙计算以及结果分类 |
| `ZeWanMoNiDialog` | 处理选择、列表、工序切换和结果显示，防止回调重入 |

工序记录使用本模块稳定的折弯编号。NX `tag_t` 仅用于当次会话，不能作为跨保存和跨拓扑修改的唯一标识；需要持久引用与几何特征共同重定位，存在歧义时要求重新识别。

模型更新在 NX 允许的会话线程执行。播放机制必须支持停止，并避免嵌套回调与长循环阻塞界面。具体调度方式通过 NX 小样验证后确定。

## 关键算法边界

1. 先验证工序离散终态，再验证中间角度。`Unbend`/`Rebend` 本身不自动提供完整、平滑且物理准确的折弯机运动。
2. 每一道折弯都需要确定固定侧和移动侧，后续折边必须随正确的板面运动。分支、闭环、压死边和多段圆弧不能用单一刚体旋转概括。
3. 几何运动采用明确的折弯半径和展开规则；不能把常量半径的角度修改默认认定为保持材料展开长度的物理成形过程。
4. 干涉检查分别记录工件与上模、下模、夹具以及可用机架模型的结果。若未提供机架、后挡料等几何，不能显示“整机检查通过”。
5. 工具与工件的正常接触需要结合接触位置判定，不能忽略所有接触，也不能屏蔽整把刀模的碰撞。
6. 只检查工序终态会漏掉运动过程中的碰撞。过程检查须包含进刀、折弯、回程及需要检查的翻转动作；离散采样应公开角度/位移步长及覆盖范围，不能宣称连续无碰撞。
7. 工件自身的碰撞不能仅依赖整个工件对整件的检测，需要可用的板片几何及邻接排除规则，独立验证后才能提供结果。

## 开发与验证顺序

### A. 几何验证小样

使用另建的测试零件验证单折 L 件、双折 U 件和反向 Z 件：识别、单道展开、重折、面重定位以及异常回滚。测量板厚、半径、角度、展开尺寸及恢复后的源几何。先确定可靠的几何路线，再接入正式界面。

### B. 可操作的首版命令

加入原生选择、工序列表、顺序调整、逐道几何状态、刀模定位和静态干涉结果。用一例明确穿透、一例仅接触、一例有间隙的实体组合核对查询结果。工艺保存须记录源模型版本信息。

### C. 过程检查和连续播放

验证中间帧生成、刀模运动、暂停恢复及过程采样，再提供连续播放。增加自定义刀模库、源零件变更失效检查和工序表导出。

### D. 扩展功能

自动折弯排序、拼刀、后挡料、整机模型、吨位与回弹估算分别作为后续功能。其输入参数和验收方法须单独确定，不混入首版已验证能力。
