# 折弯模拟首版使用说明

2026-09-21。适用环境：Windows x64、NX 2412、已安装并授权的智辉钣金插件。

本版用于单处折弯的刀具定位与当前姿态干涉检查。刀具在图形窗口中以轮廓预览；检查时临时生成真实实体，调用 NX 几何接口计算，然后回滚临时几何。

## 启动和操作

1. 打开零件，确保要检查的实体属于当前工作零件。
2. 重启 NX 使新增菜单生效，在智辉插件中选择“折弯模拟”。也可使用 NX 的“执行 NX Open”加载 `D:\UG智辉钣金插件\application\ZeWanMoNi.dll`。
3. 直接选择**内侧圆柱折弯面**或**内侧锐边**，程序自动识别。内 R 很小时先放大；圆柱面旁的相切边不会作为锐边被选中。
4. 在“刀具名称 / 截面”列表中单击刀具行，下方显示截面大图和宽高。程序自动居中定位、按折弯长度生成刀具并正视折弯截面；非对称刀具可勾选“反转刀具方向”。
5. 选择折弯、换刀或反转后自动检查，实际重叠边界显示红色。需要刷新时点击“重新检查当前姿态”。
6. “应用”检查并保留对话框与当前选择；“确定”检查后退出；“取消”直接退出。退出会清除预览；自动正视改变过的视角会恢复。

界面不再提供刀长、伸出、偏移、抬刀、倾角、定位 R 或警示间隙输入框。刀具截面来自所选刀图，刀具长度自动覆盖所选折弯；二维截面图本身不包含沿折弯轴方向的实物刀段长度。尺寸只读显示，统一为 **mm**，包括英寸零件。

圆柱折弯的内 R 直接读取模型，真正锐边按 R=0 原位定位。刀具不附加偏移、抬刀或倾角，警示间隙固定为 0.5 mm；不会给工件创建圆角。

## 结果含义

| 显示结果 | 含义 |
| --- | --- |
| 干涉 | 刀具实体与所选位置所属的整个实体发生穿透 |
| 接触 / 距离在模型公差内 | 几何接触或距离不足以区分；不自动认定为加工可行 |
| 间隙不足 | 没有穿透，但最小距离小于 0.5 mm |
| 当前姿态无干涉 | 本次静态检查没有穿透，且距离达到 0.5 mm |
| 未检查 / 未完成 / 检查失败 | 没有可用结果，需要处理输入或重新检查 |

刀具轮廓为黄色，刀具与工件实际重叠部分的边界以红色粗线显示。多个分开的干涉区域分别标出；仅接触不画红线。重叠边界来自 NX 实体求交，曲线显示的离散弓高误差不超过 0.005 mm。颜色取当前 NX 色表中最接近的黄色和红色，不修改工件颜色或色表。以文字结果区分接触、间隙不足和无干涉。

## 自定义刀具

点击“打开自定义刀具目录”，首次会生成 `example.ztool`。目录为：

```text
%APPDATA%\Zhihui\ZeWanMoNi\tools
```

将实际刀具截面按下列格式保存为 UTF-8 的 `.ztool` 文件，再点击“重新加载自定义刀具”。刀具会以“自定义：名称”加入列表，截面图自动生成。重新加载时按名称保留当前选择；若该刀具已移除或改名，则选回第一把内置刀具。

列表缩略图和下方大图显示刀具原始截面；反转效果在三维窗口中查看。大图按比例适配显示区，实际宽高以其上方的 mm 数值为准。预览图片缓存在 `%APPDATA%\Zhihui\ZeWanMoNi\thumbnails`。

```text
ZH_TOOL_V1
# 示例截面，尺寸单位 mm
name=我的直刀
0,0
5,5
5,50
-5,50
-5,5
```

每行坐标为 `X,Z`：X 横跨折弯，Z 从刀尖朝刀柄方向，刀尖必须包含顶点 `(0,0)`。沿轮廓顺序录入 3～256 个点，程序自动连接末点与首点，不要重复首点。Z 不得为负；禁止自交、重叠和连续重复点。当前支持直线多边形等截面刀具，圆弧需要按所需精度离散为线段。

最多加载 100 个文件，每个不超过 64 KB。格式错误会显示文件名和原因；修正文件后重新加载。若在打开命令时发现错误，应关闭对话框、修正相应文件，再重新打开命令。

内置三把刀具和自动生成的 `example.ztool` 都是演示尺寸。此次已另行安装用户 `折弯模拟.dwg` 中的 10 个刀型，列表名称以 `自定义：DWG` 开头。重新打开命令或点击“重新加载自定义刀具”即可显示；原有示例仍保留。

DWG 刀型包括 RZ8895、RZ30104、RW8867、RW8890、RW88100、RW88120、000、001、003、004。尺寸按原图毫米坐标提取，总高包含刀柄。004 是平底截面，以底边中点定位，只支持静态摆放与碰撞查看。圆弧转换为直线段，最大弓高误差 0.005 mm。详细来源、刀型对照及修剪记录见 [DWG 刀库说明](tool-library/dwg-20260921/README.md)。

## 当前边界

- 只检查当前刀具姿态与所选位置所属的单个实体。没有检查进刀/折弯/回程运动路径、下模、夹具、机架、后挡料及其他零件。
- 尚未实现折弯工序编排、逐道变形动画、自动排序、工艺保存或工序表导出。
- 只支持当前工作零件中的实体，暂不支持装配实例直接选择。
- 圆柱面需要能找到两侧相切的平板面；圆孔、外圆角、压死边、拆分及复杂折弯不在首版支持范围内。锐边要求连接两个非平行平面且为内侧凹边。
- 六个自动测试样件为单折 L 件；另在用户当前 `model2.prt` 多折件上验证了内 R 0.20 mm 识别、接触与局部干涉显示。尚未验证复杂箱体、孔槽附近折弯和所有生产零件形态。
- 临时轮廓可能在 NX 重绘视图后消失，换刀、反转或重新检查可再次显示。过窄的对话框可能截断较长说明文字。

诊断日志：`%TEMP%\Zhihui-ZeWanMoNi.log`。
