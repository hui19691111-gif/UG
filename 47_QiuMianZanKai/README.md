# 球面展开（NX 2412）

选择相接的圆柱面与球面或环面，生成一组连接在底带上的可展开分瓣钣金。每瓣采用圆柱弯曲面近似参考曲面，底带采用连续折弯的多边形条带。真实球面和环面有双曲率，本功能采用分瓣近似，不能视为原曲面的无变形精确展开。

## 使用

1. 打开零件，启动原菜单“球面展开”。先选圆柱面，再选同一参考体上相接的球面或环面。
2. 设置分瓣数量、瓣间隙和根部避让深度。板厚和内外侧由对应实体壁面自动识别并显示，不再手动输入或切换；尺寸以毫米输入，英寸零件自动换算。
3. 检查分瓣轮廓与理论外形偏差。需要同时获得平板时勾选“同时生成展开实体”，然后“应用”或“确定”。

输出为“球面展开_N瓣”或“环面展开_N瓣”自定义特征，内部收纳建模步骤、NX 原生“转换为钣金”特征及可选关联展开实体。即使不保留展开实体，创建时也会临时执行原生展开，检查实体法向包络是否等于板厚。创建及失败回滚期间暂停图形刷新，结束后恢复；失败时整个操作撤销，不保留半成品。

每个拉伸的截面曲线归入该拉伸的内部草图，默认隐藏，不新增散落的独立截面曲线；自定义特征将其连同拉伸一起收纳。此结构适用于新版创建的结果，旧特征组需重新生成。

双击自定义特征可以重新选面、修改参数和输出选项；编辑时保留自定义特征标识，替换旧内部建模步骤。新建模式“应用”后清空选择；编辑模式“确定”保存修改，“取消”放弃本次未提交修改。已应用结果由 NX 正常撤销管理。参考体保持完整，可选择完成后隐藏。

## 输入范围及参数

- 圆柱与球面或环面必须属于当前工作零件的同一个体、同轴相切并共享一条完整圆弧边。球面在赤道处相切；环面在圆弧截面的最大或最小径处相切，且大半径须大于小半径。支持环面的向内及向外弯曲、任意旋转放置及内外壁选择。
- 自动识别要求等厚实体：对应内外壁同轴、同心、厚度一致，具有匹配的周向范围、球冠角及圆柱高度。程序检查两段多处的内外与中间材料；片体、缺少对应壁面、变厚或歧义输入会报错，不猜测板厚。
- 支持开放周向面片及整圈回转面。整圈会自动在起始经线处留一个贯穿连接底带的开口；当前不提供独立的开缝位置选择器。
- 球面和环面圆弧从相接圆起最多到 90°；跨过顶部的面须先分割。面片边界须为经线与同轴圆形端口；不支持孔洞、不规则裁剪、样条拟合面或装配组件面。
- 瓣数为 2–180，单瓣周向角不超过 30°。板厚和间隙最小 0.05 mm；根部避让深度不小于瓣间隙，可以小于板厚，并须小于圆柱高度减板厚以保留底部连接带。
- 根部宽度会按底带内侧可用节距自动限制，避免厚板、少瓣数或窄间隙时相邻瓣在展开后重叠。界面显示实际计算的“根部缝”。朝轴线弯曲的瓣片上部继续使用输入的瓣间隙；背离轴线弯曲的环面瓣片全长限制为根部可用宽度，因而顶部间隙会增大。预览包含这一修正。
- 已验证：R100、90°、12瓣、板厚5、间隙0.5、避让6；180°、8瓣、板厚2、间隙0.5、避让4；360°、12瓣、板厚1、间隙0.5、避让3。展开仍需通过 NX 实体平面度和干涉检查，失败时保留原模型。
- 外形偏差显示为分瓣圆柱面相对于参考回转面的理论上界 `最大外壁回转半径 × (sec(单瓣角/2) − 1)`；不包含制造回弹，也不包含根部钣金转换的小圆角变化。

## 钣金与编辑约定

折弯补偿采用当前零件的 NX 钣金设置。底带尖角转换使用 NX 的“保持零折弯半径”选项；NX 2412 实际生成约 0.02 mm 内圆角。此处是几何展开验证，不代表已确定工厂的折弯半径、刀具或补偿系数。

输出依赖 QiuMianZanKaiCore.dll 和自定义特征注册。参考几何在创建或编辑确认时读取；源面修改后需双击自定义特征并确定，以重新生成。原生展开实体与生成的钣金体有关联。当前不额外创建二维展开图、折弯线或 DXF。

NX 的交互式自定义特征编辑在对话框关闭后执行构造特征更新。编辑窗口使用 `DialogModeEdit` 并沿用 NX 已建立的回滚上下文，不再嵌套回滚管理器。程序调用编辑时则单独建立回滚管理器，同步核对内部特征归属。

## 构建与发布

在本目录使用 VS2022 x64 和 NX 2412 SDK：

```powershell
cmake -S . -B build-release -A x64 -DZH_SPHERE_TESTS=ON
cmake --build build-release --config Release --target QiuMianZanKai SphereUnfoldIntegration
$env:PATH = "$env:UGII_BASE_DIR\NXBIN;$env:PATH"
.\build-release\Release\SphereUnfoldIntegration.exe G:/SphereUnfoldTest_NEW
.\build-release\Release\SphereUnfoldIntegration.exe G:/SphereRootReliefTest_NEW root-relief
.\build-release\Release\SphereUnfoldIntegration.exe G:/SphereShallowReliefTest_NEW shallow-relief
.\build-release\Release\SphereUnfoldIntegration.exe G:/TorusTest_NEW torus
python tools/deploy.py --verify-only
```

测试进程启动前需通过 UGII_CUSTOM_DIRECTORY_FILE 配置包含本项目 CustomFeatureConfiguration.xml 与 Core DLL 的 application 目录。测试目录必须使用新路径，测试自行建立并关闭专用零件，不打开用户模型。`tools/generate_resources.py` 用于生成对话框及图标。可选 `SphereUnfoldUITest` 目标使用安装目录的授权库调用原样受保护 Release 命令，仅供界面测试，不部署。

完成真实 NX 对话框回归后，运行 `python tools/deploy.py`。脚本部署 UI/Core DLL、DLX、BMP，仅合并本命令的自定义特征声明并保留其他注册项；先备份原文件及清单，再更新 SHA-256、字节数和依赖。保留授权入口、保护编译、ASLR、DEP及有效 PE 校验和；不部署测试程序或调试产物。首次安装自定义特征版本后需保存零件并重启 NX。

环面中心平面从共享的相切圆弧获取，并用曲面边界采样核对圆弧截面；不能把 `UF_MODL_ask_face_data` 对修剪环面返回的任意轴上点直接当成环面中心。可选 `SphereUnfoldModelTest` 目标会将输入零件复制到全新路径，仅对副本执行识别、创建、展开、归属检查及保存；只读输入的副本会单独赋予写权限。
