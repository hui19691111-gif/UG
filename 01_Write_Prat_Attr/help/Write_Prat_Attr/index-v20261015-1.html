写入部件属性

给当前工作零件填写客户、机型、名称、图号、颜色、材料和数量。零件里的每个实体还会写上同样的材料。装配里的其他子件不会一起改。

先看这个功能写到哪里

适合

  • 只填当前这一个零件。
  • 材料要同时写到这个零件里的全部实体。
  • 在装配里，已经把要填的子件设成了工作部件。

不要用它来做这些事

  • 一次改装配里很多零件：用“批量写入部件属性”。
  • 统计焊件数量：用“自动分层与统计焊件数量”。
  • 它不会写 sulian、编号或图层。

四步写完

装配里最容易写错零件。只在装配导航器里点亮一个组件，工作部件并没有变。写入对象永远是当前工作部件。

对话框每一项写到哪

界面写入后的属性
客户零件属性“客户”
机型零件属性“机型”
零件名称零件属性“名称”。打开时默认是当前零件名，可以改
编号零件属性“图号”
颜色零件属性“颜色”
材料零件属性“材料”，同时写到每个实体的 cailiao
数量零件的整数属性“数量”。实体上没有数量
打开配置文件打开客户、颜色、材料的下拉列表文件，本身不写属性
确定写入并关闭。应用写入但窗口留着。取消只放弃还没提交的内容；已经点过“应用”的不会被取消撤回。

数量怎么填

0、负数、小数、空着、带“件”或单位，都会被拒绝，并提示“数量必须是大于 0 的整数。”

增加客户、颜色、材料

点“打开配置文件”，编辑：

D:\UG智辉钣金插件\config\Write_Prat_Attr.ini

可以改的三组

[客户] [颜色] [材料]

分组名下面一行一个选项。可以增删，也可以调整顺序。不要删掉方括号里的组名。

空行，以及以 # 或 ; 开头的行会被忽略。重复选项会自动去掉。

改完怎样出现在下拉框

  1. 用记事本保存，编码用 UTF-8。
  2. 先关掉记事本，再关掉当前对话框。
  3. 重新打开“写入部件属性”，下拉列表才会更新。

[Dialog] 记的是上次用过的值，一般不用手改。

写完后去哪里核对

看哪里应该有不应该有
当前零件属性客户、机型、名称、图号、颜色、材料、数量
当前零件的每个实体cailiao，值和材料一致客户、机型、名称、图号、颜色、数量
装配里的其他子件保持原样不会被这次操作改掉
点确定或应用之后，还要保存零件文件。关闭时选择不保存，这次填写的属性会丢掉。

遇到这些情况

现象怎么处理
写到了别的零件执行前看 NX 的工作部件，不要只看显示部件或选中的组件。
其他子件没一起写上这是正常的。要逐个设为工作部件，或改用批量写入。
实体上没有数量数量只属于零件。实体只看 cailiao。
新加的选项不在下拉框里确认 ini 已保存，然后关掉对话框再打开。
点取消后属性还在之前已经点过应用。取消不会撤回已经写入的内容。
右上角问号没有内容确认 D:\UG智辉钣金插件\application\Write_Prat_AttrHelp 里有本页和 map 文件，然后重新打开这个命令。
打不开配置文件看日志 D:\UG智辉钣金插件\logs\Write_Prat_Attr_open_config.log。里面有这次为什么没打开，把该文件发给支持人员。
还是失败看日志 D:\UG智辉钣金插件\logs\Write_Prat_Attr.log。
