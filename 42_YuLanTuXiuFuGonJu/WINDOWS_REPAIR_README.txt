UG智辉钣金插件预览图修复工具
==================================
适用系统：64 位 Windows 10 / Windows 11

使用方法：
1. 双击单个文件“UG智辉钣金插件预览图修复工具.exe”。
2. 先点“重新检测”，再点“一键修复”。
3. Windows 请求管理员权限时选择“是”。
4. 关闭并重新打开 .prt 文件夹，或按 F5 刷新。

作用：
- 修复 .prt 文件关联的 Windows 缩略图处理器。
- 兼容 64 位 Windows 10 和 Windows 11。
- 只读取 .prt 文件里的 NX 原生 JPEG 预览，不启动 UG/NX，不修改模型。
- 可在程序内点“卸载修复”恢复。

重要说明：
- 本工具修复的是 Windows 文件浏览器的“显示”功能。
- 如果某个 .prt 文件内本来就没有原生预览，修复 Windows 后仍不会显示。
- 此时需在 NX 的“显示部件属性 -> 预览”中开启“保存预览”和“存储预览”，都设为“部件保存时”，然后保存零件。
