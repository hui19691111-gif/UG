# 板件调尺

NX 2412 C++ Block UI Styler 插件，用于调整平板、封闭钣金和门板的长宽尺寸。

## 调整方式

- 每侧独立：分别输入左、右、下、上四侧位移；正值向外，负值向内。
- 统一调整：输入长度和宽度增量，正值加大、负值缩小，并通过九点基准确定固定位置。
- 取整：长度、宽度可分别按指定步长就近、向上或向下取整。

选择板件主平面后，程序以该平面的最长直线边作为长度方向；可使用“交换长度、宽度方向”切换。实时预览通过 NX 不可见撤销标记实现，取消对话框会恢复原模型。

调整尺寸时，外圈折回裙边的内外壁、折弯面和自由端随对应侧同步移动，保持各侧原有裙边宽度。程序在移动后复测截面；无法完整识别裙边或校验不通过时撤销本次调整。中央开孔不作为固定裙边宽度的基准。

## 构建

1. 确保 `UGII_BASE_DIR` 指向 NX 2412 安装目录。
2. 运行 `tools\generate_dlx.ps1` 重新生成对话框文件。
3. 使用 Visual Studio 2022 构建 `Release|x64`。

输出位于 `bin\Release`。

## 几何回归验证

构建 `tests\SkirtGeometryTests.vcxproj` 的 `Release|x64`，将 NX 的 `NXBIN` 加入 `PATH` 后运行 `bin\Tests\SkirtGeometryTests.exe`。测试使用独立 NX 会话生成临时板件，不保存零件，不修改当前打开的模型。覆盖平板、普通折边、带大开孔且四侧裙边宽度不同的板件、带内外圆角的折回裙边，以及正反面选取、四侧放大/缩小、连续调整和撤销后再次调整。

测试与插件共用移动提交和截面校验代码，包含 NX 成功移动但不返回特征对象的情况，并检查失败回滚、取消恢复外形尺寸和应用后保留结果。

## 诊断日志

运行日志默认写入安装根目录下的
`logs\TiaoZenBanLeiCiCun.log`。日志超过 5 MB 后会保留一份
`TiaoZenBanLeiCiCun.previous.log` 并开始新日志。若安装目录不可写，
则回退到系统临时目录的 `UGZhihuiLogs` 文件夹。

## 用户参数

对话框会自动记住调整方式、取整方向、固定基准、方向交换和实时预览
开关。每次重新打开对话框或重新选面时，四侧偏移和长宽增量都会清零；
重新打开时长度、宽度取整步长均恢复为 1。参数文件位于安装根目录下的
`config\TiaoZenBanLeiCiCun.settings`。
