# 板件调尺

NX 2412 C++ Block UI Styler 插件，用于调整平板、封闭钣金和门板的长宽尺寸。

## 调整方式

- 每侧独立：分别输入左、右、下、上四侧位移；正值向外，负值向内。
- 统一调整：输入长度和宽度增量，正值加大、负值缩小，并通过九点基准确定固定位置。
- 取整：长度、宽度可分别按指定步长就近、向上或向下取整。

选择板件主平面后，程序以该平面的最长直线边作为长度方向；可使用“交换长度、宽度方向”切换。确定或应用会在特征树写入一条“板件调尺”自定义特征。之后在特征树双击这条特征，会回到原对话框并带出当时的板件和偏移，改完再确定就会更新同一条特征。自定义特征类在 NX 启动时加载；若当前会话还没有这个类，确定和应用会直接提交当前预览，不会弹出英文错误。完全退出并重新启动 NX 后，新的结果才能在特征树双击修改。实时预览在确定之前仍只编辑当前预览，不会把每次改数都变成新特征。取消对话框会恢复原模型。长宽显示会采样圆弧边，避免只统计端点时漏掉圆角或卷边的最外点。

调整尺寸时，外圈折回裙边的内外壁、折弯面和自由端随对应侧同步移动，保持各侧原有裙边宽度。板厚按外圈截面上最近的平行平面识别，板面中间的浅凸台不会被当成板厚。某一段边界没有走通时，只要同侧其它截面已经到达对面皮，调整仍会继续；无法追踪的曲面或整侧都走不通时撤销本次调整。中央开孔不作为固定裙边宽度的基准。

## 构建

1. 确保 `UGII_BASE_DIR` 指向 NX 2412 安装目录。
2. 运行 `tools\generate_dlx.ps1` 重新生成对话框文件。
3. 使用 Visual Studio 2022 构建 `Release|x64`。

输出位于 `bin\Release`。

## 几何回归验证

构建 `tests\SkirtGeometryTests.vcxproj` 的 `Release|x64`，将 NX 的 `NXBIN` 加入 `PATH` 后运行 `bin\Tests\SkirtGeometryTests.exe`。测试使用独立 NX 会话生成临时板件，不保存零件，不修改当前打开的模型。覆盖平板、普通折边、带大开孔且四侧裙边宽度不同的板件、带内外圆角的折回裙边，以及正反面选取、四侧放大/缩小、连续调整和撤销后再次调整。另有一块带中间浅凸台的平板，用来确认板厚仍取自外圈截面。另有一次先创建移动面、再把距离从 5 改成 12、再改成 3 的检查，确认编辑后仍是同一条特征，位移等于最后一次距离。

测试与插件共用移动提交和截面校验代码，包含 NX 成功移动但不返回特征对象的情况，并检查失败回滚、取消恢复外形尺寸和应用后保留结果。

## 诊断日志

运行日志默认写入安装根目录下的
`logs\TiaoZenBanLeiCiCun.log`。日志超过 5 MB 后会保留一份
`TiaoZenBanLeiCiCun.previous.log` 并开始新日志。若安装目录不可写，
则回退到系统临时目录的 `UGZhihuiLogs` 文件夹。

## 用户参数

对话框会记住调整方式、四侧偏移、长宽增量、取整方向、取整步长、固定基准、方向交换和实时预览开关。这些值在重新打开对话框或重新选面时都会保留。参数在应用或取消时写入安装根目录下的 `config\TiaoZenBanLeiCiCun.settings`。
