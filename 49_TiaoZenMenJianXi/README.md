# 查看调整门间隙

NX 2412 插件。选择门板主平面后，按该门板实体四侧的外边界，寻找邻近实体的平行内侧面，在模型中同时显示左、右、下、上四个常显编辑框。编辑框锚在相应直线边的中点，旋转或缩放视图时随边移动；直接输入目标间隙并单击对话框的“应用”修改门板边界。对话框只保留选面、提示和操作按钮，不重复显示四边数值。

多实体零件可直接操作。装配中可保持总装配为工作部件，直接选择门板组件的显示面；应用时会临时切换到该组件的零件，修改后恢复原工作部件。邻件可以属于其他组件。只编辑所选门板的零件，不移动框架。若同一零件在装配中有多个实例，修改会同步作用于这些实例。每侧使用 NX Move Face，保持钣金折回边的截面；提交前复测四侧，失败时回滚本次全部修改。没有合格邻件的边显示“--”，输入框不可编辑。

适用条件：门板为有直线边的平面，邻件有覆盖该侧至少 15% 长度的平行平面，目标间隙为 0～100 mm。门板角部 R 角应先去除；复杂曲面或无法完整识别折回边时拒绝修改。四侧按模型坐标定位，优先选取与全局 Z 轴垂直的边作为左右方向，竖直门板的“上”取全局 Z 正方向。

构建：运行 `tools\generate_dlx.ps1`，然后使用 Visual Studio 2022 构建 `Release|x64`。构建需要 `UGII_BASE_DIR` 指向 NX 2412 安装目录。运行 `deploy_release.ps1` 安装到 `D:\UG智辉钣金插件`，脚本会先备份旧文件和清单，更新按钮和哈希，再核对 PE 校验和及文件哈希。

参考：[博士钣金官网“修改门板间隙”](https://bsbanjin.com/bsjc)。官网注明支持装配体、多实体，并要求门板先删除 R 角。本插件针对 NX 实现，不使用其源码或模型。
