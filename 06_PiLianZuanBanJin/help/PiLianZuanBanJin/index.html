先判断：是不是该用“批量转钣金”

适合这些情况

  • 一个零件里有多个等厚薄壁实体，需要统一转换并展开。
  • 装配中有很多零件，需要按筛选条件批量处理。
  • 零件已经是钣金体，但需要补建或更新展开。

这些情况先不要用

  • 实体不是等厚薄壁体，或几何本身不能按钣金规则展开。
  • 只处理一个特殊零件并且必须精确指定基面，可优先用“手动转钣金”。
  • 材料、数量、板厚或折弯规则尚未确认，先补齐资料再批量运行。

完成后你会看到

  • 普通实体变成钣金体，并具有折弯规则和展开。
  • 已有钣金体的展开得到补充或更新。
  • 成功体、失败体按所选显示方式隐藏、变红或高亮。

按当前模型直接选路线

普通等厚实体使用自动处理，先小批量验证基面、规则和展开。
原来就是钣金体直接参加批处理，完成后检查展开是否更新或补齐。
装配中有很多零件先在部件列表筛选并勾选，再进入主参数界面。
个别件基面总不合适先用“手动选择…”指定基面和 X 方向。
大板和螺母柱在同层开启紧固件过滤；每层只要一块主板时再开“每层最大”。
第一次试新规则关闭自动保存，只处理 2～3 个零件并检查结果。

一、第一次使用：照这 7 步操作

多数零件不需要手动选面。先设好规则和筛选范围，点击“确定”后即可批量完成转钣金、折弯系数设置和展开。

  1. 打开模型。可以打开单个零件，也可以在装配中运行。装配环境会先让你勾选要处理的子部件。
  2. 先点“规则设置…”。确认材料、板厚、折弯条件对应的中性因子规则已经正确保存。
  3. 选择固定面方向。成品主要向下折就选“下折多”；主要向上折就选“上折多”。
  4. 填写工艺参数。按企业工艺填写避让槽深、避让槽宽和内 R 半径；不确定时先使用验证过的默认值。
  5. 限定处理范围。通常勾选“按图层范围找实体”，填写起始、结束图层，并按需要排除小实体和紧固件。
  6. 决定是否自动保存。试运行建议先关闭；确认规则正确后再开启，以免批量保存不需要的结果。
  7. 点击“确定”。等待处理完成。若有失败，根据颜色、高亮或结果信息定位失败体。
推荐：第一次处理一批新类型零件时，先拿 2～3 个零件试跑，确认基面方向、中性因子和展开结果，再扩大范围。

二、主对话框真实界面

主对话框真实界面。先设置系数策略，再设置高级过滤，最后按本页说明执行“手动选择…”或“确定”。

界面从上到下分为两组

  1. 系数策略：决定怎样找基面、固定面朝向、失败后的显示方式、展开基面颜色，以及转钣金使用的基础工艺参数。
  2. 高级过滤：决定哪些实体参加本次批量处理，例如图层范围、最小尺寸、是否排除螺母柱，以及是否每层只取最大实体。
注意：截图中的红箭头是原截图已有标注，指向“规则设置…”。用户实际使用时，右侧不会出现教程中的说明文字。

按钮的基本区别

“手动选择…”会立即进入逐个实体的人工选面流程；“确定”则按当前参数自动处理尚未手动处理的对象。

三、每个选项怎么用

第一次使用不必逐项阅读；只有不清楚某个开关时再展开查询。

界面选项作用什么时候使用

内 R 半径创建转钣金时采用的内侧折弯半径。有统一工艺要求时填写；不同材料或板厚应先验证。
跳过过小实体启用最小长度、最小宽度过滤，小于限制的实体不参与处理。模型里有碎体、辅助体或非常小的非产品实体时开启。
跳过螺母、螺柱、螺钉识别并排除常见紧固件类实体，避免把螺母柱误当钣金体转换。一个零件内同时存在钣金大板和紧固件实体时建议开启。
按图层范围找实体只处理起始图层到结束图层之间的实体；起止数值填反也会按较小层到较大层使用。按图层组织加工对象时建议常开，例如只处理 1～99 层。
每层只处理最大实体同一图层有多个候选实体时，只保留包围盒体量最大的一个。每层确实只放一件主板、其他都是附件时开启。若同层有多件都要处理，必须关闭。
规则设置…打开插件内置的折弯系数规则表，维护材料、板厚、折弯类型与中性因子的对应规则。第一次使用、材料/板厚变化，或发现展开长度不对时先检查这里。

在主对话框点击“规则设置…”会打开下面的真实界面。这里决定不同材料、板厚和折弯角度采用哪一列扣除值或 K 因子。

真实“折弯系数表”截图。表格中的数值仅代表截图当时的数据，正式生产请使用本企业已经验证的工艺数据。

展开规则表各项说明
区域或控件作用与操作方法
选择规则选择要维护的折弯角度区间，包括 90°、0～90°、90～180°、180～360°。每个角度区间可以分别指定普通折弯和多刀折圆使用的系数列。
普通折弯指定普通折弯从“扣除1～3、K因子1～3、A1～A3”中的哪一列取值。截图中选择的是“扣除1”。
多刀折圆指定多刀折圆采用的系数列。截图中选择的是“K因子3”。
多刀折圆最小半径用于区分普通折弯与多刀折圆的半径门槛。大于 0 时启用；达到门槛的圆弧折弯按“多刀折圆”列取值。单位跟随当前零件单位。
材料分页选择“全部”查看所有材料，或只查看某一种材料，便于在材料较多时维护。
新增厚度为材料增加一个厚度规格。通常会基于当前选中行建立新行，再修改厚度和各列工艺值。
系数表格双击需要修改的单元格，维护材料、厚度及扣除值/K 因子。A1～A3为预留的附加系数列，只有上方规则选中对应列时才参与计算。
保存把当前规则写入配置文件。建议每次修改完成后立即保存。
导入/导出EXCEL数据按钮名称虽写“EXCEL”，实际选择和生成的是 .csv 文件；导入后先核对材料、厚度和小数，再点击“保存”。
计算K因子打开 K 因子计算工具，根据试折或已知展开数据辅助计算，再把结果填入相应列。
确定 / 取消“确定”会保存当前修改后关闭；“取消”只放弃尚未保存的修改。若此前已经点过“保存”，再点取消也不会恢复旧规则。
规则选择要一致：若普通折弯选择“扣除1”，请维护当前材料和板厚行的“扣除1”；若多刀折圆选择“K因子3”，请维护“K因子3”。不要只修改某一列，却在上方选中另一列。

五、怎样让展开基面符合要求

自动基面会同时参考折弯朝向、平面大小、平面在板件中的位置、附近折弯数量和内孔情况，所以结果不一定是面积最大的那个面。使用时按下面的方法设置和检查即可。

  1. 先选折弯方向。成品主要向下折时选“下折多”，主要向上折时选“上折多”。方向选反会使基面落到另一侧。
  2. 有规范标记线时再开启标记线。标记线必须可靠地表达需要保留的一侧；不确定时先关闭，避免错误标记影响结果。
  3. 开启“展开基面颜色”。处理完成后直接查看被着色的面，确认它是否是希望固定的基面。
  4. 抽查展开方向。打开展开特征，确认 X 方向、折弯朝向和展开外形符合出图及加工要求。
  5. 自动结果不合适时手动指定。点击“手动选择…”，选择目标平面及该平面上的直线边；不要反复修改无关参数碰运气。
为什么不是最大面：这是正常情况。最大面只是参考之一，更靠近板件主要区域、附近折弯更多或方向更合适的平面也可能成为基面。
不要只看颜色：着色用于告诉你本次选了哪个面。最终仍要打开展开结果，检查方向、尺寸和折弯是否正确。

六、不同模型情况应该怎么操作

先判断模型属于下面哪种情况，再按对应方法设置。这样可以避免漏转、重复处理或把附件当成钣金体。

  1. 普通等厚实体：先确认材料、数量、图层和板厚信息正确，再设置避让槽、内 R 与折弯规则。点击“确定”后，应得到转钣金、中性因子和展开结果。
  2. 本来就是钣金体：可以直接参加批处理。完成后检查已有展开是否更新；原来没有展开的实体应新增展开结果。
  3. 同层有大板和螺母柱：开启“跳过螺母、螺柱、螺钉”。如果该层只允许一块主板，再开启“每层只处理最大实体”。
  4. 同层有多块都要处理的板：关闭“每层只处理最大实体”，否则该层只会处理一个体。
  5. 模型含碎体或辅助体：开启“跳过过小实体”，把最小长度、最小宽度设为能够排除碎体但不误伤小钣金件的数值。
  6. 只处理指定层：开启图层范围并填写起止层；处理结束后，范围外的实体应保持不变。
  7. 个别零件方向特殊：先用“手动选择…”处理这些实体，再回到主窗口点“确定”处理其余对象。
  8. 需要检查失败对象：选择“失败体改红色”或“高亮失败体”；处理后逐个打开失败零件，检查板厚、材料、基面、X 向边和几何是否可展开。
  9. 首次验证新规则：关闭自动保存，只处理少量零件。确认展开尺寸、基面和折弯方向正确后，再开启自动保存进行正式批处理。
完成后应看到：普通体成为可编辑钣金体，并具有折弯规则和展开；已有钣金体的展开得到补充或更新；源体和展开结果具有可供后续出图使用的展开尺寸信息。
取消不能当作撤销：批处理或手动处理已经开始后，模型中可能已经产生钣金和展开结果。需要恢复时请使用 NX 撤销、关闭不保存或还原备份；关闭本对话框不会自动恢复已完成的实体。

七、手动选择基面和 X 方向

本图为手动选择基面阶段：在模型中点选目标平面后确认；随后 NX 会继续提示选择该面上的直线边作为 X 方向。

  1. 在主对话框中先设置好避让槽、内 R、颜色和失败处理方式。
  2. 点击“手动选择…”，在模型上选择需要处理实体的平面作为固定基面。
  3. 按提示选择刚才基面上的直线边作为 X 方向。圆弧边或不在该面上的边不能作为有效 X 向边。
  4. 当前实体完成后可继续选择下一个特殊零件，直到所有需要人工定向的实体都处理完。
  5. 不再手动处理时取消选择，返回主对话框。
  6. 若还要自动处理其他实体，再点击主对话框“确定”；已经手动处理过的实体不会重复进入本次自动处理。
  7. 主对话框开启“运行完成自动保存”时，手动处理完成的部件也会保存；试运行时建议先关闭。
手动选择的意义：它是给少数特殊件兜底，不建议把整批零件都逐个手选，否则会失去批量处理的效率。

单零件

装配

装配环境运行时，先出现下面的真实部件选择窗口。筛选并勾选要处理的子部件，确认后才进入主参数对话框。

控件使用说明
过滤输入部件名或列表中显示的属性关键字，列表立即缩小到匹配项。
层可选择按“部件图层”或“装配图层”过滤。前者看子部件内部对象所在层，后者按组件在装配中的层判断。

  • 普通实体完成后应具有转钣金、中性因子和展开结果。
  • 已有钣金体完成后应保留原钣金结果，并更新或补充展开。
  • 开启自动保存时，被处理的子部件会保存；关闭时请在检查后自行保存。
自动保存提醒：装配批处理时会保存被处理的子部件。正式运行前请确认文件可写，并建议保留版本或备份。

九、四种常用设置方案

普通钣金零件批处理

图层范围开启；按零件方向选择上折多/下折多；展开基面颜色开启；先关闭自动保存试跑。

大板与螺母柱同层

开启“跳过螺母、螺柱、螺钉”。若该层只应处理大板，也可开启“每层只处理最大实体”。

同层有多件钣金都要转

关闭“每层只处理最大实体”，否则每层只会留下一个最大候选体。

个别件基面方向特殊

先用“手动选择…”处理特殊件，再返回主对话框点击确定处理剩余对象。

十、常见问题与排查

为什么某个实体完全没有处理？

依次检查：是否在图层范围内；是否被“过小实体”过滤；是否被识别为紧固件；是否开启了“每层只处理最大实体”；装配列表中是否勾选了对应部件。

为什么选到的基面不是面积最大的面？

自动基面还会参考折弯方向、所在位置、附近折弯和内孔，面积只是其中一项。可开启基面颜色核对，再调整上折/下折偏好、检查标记线，或改用手动选择。

为什么大板同层的螺母柱也被处理？

检查“跳过螺母、螺柱、螺钉”是否开启；如果每层只需要主板，再开启“每层只处理最大实体”。注意“最大实体”按实体包围盒体量比较，不按单个面面积比较。

为什么批量到后面越来越慢？

复杂零件、历史特征较多、反复转换或反复展开都会增加更新时间。先用图层和尺寸过滤减少对象；已经多次试转的零件可另存干净版本后再处理，并避免同一批次重复选择相同部件。

点击“规则设置…”报 NX error code=352019 怎么办？

先完全退出 NX，再重新启动并重试。仍报错时，请使用同一版本的完整安装包执行修复安装，不要只替换单个文件；问题仍存在时记录错误码、NX 版本和日志交给管理员。

更新插件后点击没有反应怎么办？

完全退出 NX 后重新启动。仍无反应时，用完整安装包重新安装或修复插件，确认安装目录可写；不要在 NX 运行中替换插件文件。再次失败时联系管理员检查更新日志。
