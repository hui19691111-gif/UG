# 方通 / 圆管伸直（NX 2412）

从弧形或转角方通生成带切口的直方通下料实体。保留弯曲外侧整面原壁厚，另外三面去料；原模型保留。连接壁的展开长度计入内弯半径和 K 系数，切口按回折时的对合位置生成。

同一菜单增加弯圆管伸直：自动识别外径和壁厚，沿圆周开口，在弯曲外侧保留连续连接带的原始径向壁厚。输出是带切口的直圆管，不是把圆管剖开摊成平板。

## 使用

1. 点击**一个贯通两端的外侧完整大平面**，程序自动从这个面识别整条直线/圆弧路径。不要选择端口、内壁、圆角面或仅属于某个直段的小面。
2. 自动识别截面宽、高、壁厚、截面圆角和管壁孔槽。设置每条圆弧切口数（2–180）、连接壁内弯半径、K 系数和切口间隙。尺寸输入单位为 mm，英寸零件自动换算。
3. 检查预览的切口、伸直长度及分段偏差，点击“应用”或“确定”。下料件与原方通的起始端截面重合，沿该端切向伸直，不再附加横向偏移；可选隐藏原体，避免起始段重叠显示。

### 圆弧多段伸直 / 弯管机成型

- **圆弧多段伸直**初始默认开启（NX 会话内可能恢复上次开关状态）：沿用原来的圆弧分段、连接壁 K 系数、V 形切口和原管同步开槽逻辑。
- 关闭后，圆弧按模型真实半径整体计长，生成连续直管，供弯管机成型；不会在圆弧区域切槽，也没有折线近似误差。相切的直段与多段圆弧可一起处理，尖角仍使用原切口方式。
- 新增独立的**弯管 K 因子（0.5 为中心线）**输入框，关闭开关时显示。这里 K 定义为中性层距管内侧的距离除以截面高度 H（圆管为外径），圆弧展开长为 `[R外 − H + K×H] × θ`。默认 0.5 按几何中心线长度下料；它不是原来按单层壁厚计算的“连接壁 K 系数”。K 随成功应用记忆，默认不额外添加夹持余量。
- 中性层位置会随管材及机床设定变化；此 K 是工艺校准输入，不自动预测拉伸、压扁或回弹。工艺背景见 [Bend Tooling 中性层说明](https://bendtooling.com/encyclopedia/neutral-axis/) 和 [管弯公式与机床设定](https://bendtooling.com/tube-bending-formulas/)。
- 纯圆弧整体伸直时，切口数、连接壁半径/K、间隙、连接带及原管开槽均不参与计算；已有“原管开槽”勾选也不会切圆弧。若混有尖角，同步开槽只作用于尖角。起始端对齐、原管隐藏及整次撤销继续有效。
- 完全位于平直管壁的孔槽按真实直段位置映射，保留孔形、尺寸及理想成型后的对应位置；弯曲区域内或跨弯孔槽不能按刚体映射，整体模式会明确拒绝，原分段模式继续可用。圆管带孔槽仍属于既有不支持范围。

### 同时在原管切间隙槽

- 勾选 **在原管件上切间隙槽（同时伸直）**，应用后直接在所选原管上增加去料特征，并照常生成伸直下料件；原管的位置、圆弧和转角外形保持不变。
- 槽数及分段位置与伸直切口对应。弧形槽位落在真实圆弧上，转角槽沿两段切向的角平分截面；槽的两侧平行，“切口间隙”是这两面之间的距离，须至少为 0.01 mm。
- 方通保留弯曲外侧完整壁厚；圆管保留外侧连接带的完整径向壁厚。圆弧连接带按实际曲面保护，不用直线平面代替曲壁。孔槽冲突时调整分段或拒绝生成，不移动原孔。
- 创建时开关默认关闭（NX 可能恢复会话设置）；编辑时回填特征保存的开关。开启时“完成后隐藏原管”禁用，开槽后的原管保持可见；关闭开关仍按原来的伸直流程，原管不去料。
- 原管开槽和生成伸直件共用一次撤销；任一步失败会全部回滚。需要改参时双击“方通/圆管伸直”自定义特征，原管槽与下料件一起更新。此选项提供原形上的槽口对照，不是材料折弯或回弹模拟。

### 圆管选择与连接带

- 点击圆管上的一个面即可识别整条管；选择环形端口可指定伸直起始端。可处理同平面、同向的圆弧弯管、相切的直管/弯管组合及相交轴线的转角管；支持垂直圆环端口和直段上的平面椭圆斜端口。
- “圆管连接带弧宽”按外圆周弧长计，默认 6 mm，可调整。最大为外圆周长的四分之一；该参数不影响方通。连接带位于弯曲外侧，保留完整径向壁厚，其余圆周开切口。
- 圆管起始圆环截面与原管重合；原模型保留，可以勾选隐藏原管查看结果。
- 圆管孔槽、变径、分支、S 形及空间弯管暂不支持，会提示并取消生成，避免产生漏孔或不完整的下料件。方通原有的平壁孔槽功能保留。
- 斜端口在两种伸直模式下均保留原平面角度、方向和完整壁厚，选斜端口作为起点也能原位重合。预览同时显示斜口与含尖端总长；通常的“伸直长度”计至两端平面与轴线的交点。斜切延伸到弯曲区或与伸直切口相交时拒绝生成。STEP 导入圆环面的轴向中心点采用解析圆边界校正，并继续核对整管体积。

## 几何和加工范围

- 当前支持工作零件内单个实体、等壁厚的矩形/正方形空心管，含四角等半径的圆角矩形截面，路径由同一平面内同向的直线与真圆弧构成。
- 端口必须垂直路径且截面一致；单个转角不超过 135°，总转向不超过 180°。暂不支持 S 形、空间弯曲、变截面、样条或闭合环。圆弧与相邻直段须相切。
- 连接方式固定为保留外侧整面管壁，不是小连接桥。内弯半径应小于截面高度减两倍壁厚。切口相互重叠、越过端部或剩余料过短时拒绝生成。
- 切缝是沿直管轴向附加的几何开口，不是激光刀路补偿值。切缝为 0 时，远离连接圆角的切口面在理论回折后对合；正切缝保留装配间隙。
- 弧形采用外切折线近似，显示 `R外 × (sec(单步角/2) − 1)` 的折线外形偏差。这个数不含连接处实际圆角、材料回弹或工艺误差。
- 连接壁有限厚度的折弯会产生内外圆角。尖角参考体只能恢复到对应的直段位置和方向，连接处会按设定半径过渡；弧形也不能恢复为完全连续的原圆弧。
- 当前输出三维下料体，不生成 DXF、激光刀路、回弹模拟或折后实体。实际半径、K 系数及最小可加工切口需按材料和工艺校准。

## 孔位保留

- 支持平直管壁上垂直贯穿单层壁厚的圆孔，以及直线/圆弧构成的闭合等截面槽。双面贯穿孔按两个管壁开口处理，界面显示的是开口数。
- 每个孔槽随所属直段做同一个刚体变换，保留轮廓、尺寸和对应的回折位置。不会沿长度比例缩放孔距，也不会为了避让切口移动孔。
- 圆弧分段默认等角度；若孔槽与切口冲突，程序尝试调整内部切向位置，保留切口数和两端切向。调整后显示实际最大分段偏差。若仍不能保证完整孔形，会拒绝生成并提示调整切口数。
- 原孔必须完整落在一个可回折直段内，并与切口、连接折弯区及截面圆角保持间隔。盲孔、沉孔、斜孔、圆柱曲壁上的孔、跨弯孔和开放缺口暂不支持；识别不完整时不会生成一个漏孔的下料体。
- “孔位保留”指按规划分段进行几何回折后的对应位置。原连续圆弧仍为分段近似，制造回弹和实际弯曲变形需工艺校准。

## 算法

对转向角 θ（弧度）、内弯半径 R、壁厚 t，连接壁折弯展开量为 `(R + K×t)×θ`，外侧退让量为 `(R+t)×tan(θ/2)`。伸直长度等于外侧折线路径长度减两侧退让，再加各折弯展开量。K 系数的中性层定义参考 [SOLIDWORKS 官方说明](https://help.solidworks.com/2025/english/solidworks/sldworks/c_K_Factor.htm)。

切口在连接壁内表面截止。内圆角深度内保留根部避让开口，再接 V 形斜切面，避免把有限半径折弯当成零厚度铰链。识别同时检查两端圆角截面、支持的面类型、孔槽穿壁边界，以及扣除全部孔槽后的理论体积与原体体积，拒绝不符合规则方通的输入。
