# 孔防拉料检查

用于检查成形钣金件中靠近折弯区、可能在折弯时被拉变形的封闭通孔孔壁。

当前版本：

- 可选择一个或多个钣金实体；未选择时检查工作部件内全部实体。
- 自动识别具有至少两条直母线边的圆柱折弯面，并以其直边作为折弯切线边。
- 仅处理普通折弯；直接读取 NX 钣金折弯的内R和板厚，内R 大于或等于 3 倍板厚时按大圆弧折弯排除。
- 收集平面和已验证折弯圆柱面上的 Hole 内环，并按相邻孔壁合并正反面孔口；不检查外轮廓开口或普通侧壁。
- “识别通孔”统计所有经正反孔口及板厚验证的封闭通孔，包括局部凸台、压形面上的圆孔和异形孔；仅与普通折弯切线边直接相连的平面孔口参与风险距离判定和自动开槽。
- 允许通孔另一侧孔口位于未连接折弯的平面或折弯圆柱面。距离和防拉槽定位仍取与折弯切线边相连的平面孔口。
- 支持圆孔、长圆孔及由直线、圆弧、椭圆弧或样条边组成的封闭异形孔。标准长圆孔按直线段长度 L 分档；其他非圆轮廓按孔口包围盒对角线分档。
- 实际距离取折弯侧平面内环边到相连折弯边的最小距离；小于配置公式计算的安全距离 S 时，高亮该孔的孔壁面。
- 默认圆孔公式：`t ≤ 2` 时 `S=t+r`，`t > 2` 时 `S=1.5t+r`。
- 默认长孔公式：`L ≤ 25` 时 `S=2t+r`，`25 < L ≤ 50` 时 `S=2.5t+r`，`L > 50` 时 `S=3t+r`。
- 安全距离可选“公式自动识别”或“手动输入”；公式的折弯内R固定按 `+r` 计算，无R倍数和附加预留。
- 同一通孔在板件正反面形成的两个内环按共享孔壁合并，只统计为一个风险孔。
- 非风险面以 85% 通透显示；关闭对话框后恢复原显示状态。
- 记忆安全距离模式、防拉槽长度模式、手动值和槽宽（默认 0.2 mm）。
- 开槽沿折弯线的位置由“折弯边向内环方向偏置拉料风险距离”与内环的两个交点确定，取两交点中点作为槽中心定位。
- 防拉槽长可选“自动识别”或“手动输入”；自动值为两交点距离加上两端各 1 mm。
- 单击“应用”或“确定”后，先展开对应折弯，在上述位置对应的折弯中心线上创建矩形贯穿槽，再重新折弯。
- 已替换正式部署中的旧 `ChaiJiJia / 拆机架` 入口，发布命令名为 `KonFanLaLiao`。
- Release 构建沿用被替换部署槽的 `ZHIHUI.CHAIJIJIA` 授权码调用统一授权网关。

